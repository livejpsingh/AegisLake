# 📊 Power BI Executive Risk Cockpit Guide

This guide walks you through building an **Executive FinTech Risk & Loss Mitigation Dashboard** in **Power BI Desktop** using datasets generated by AegisLake.

This directly fulfills the hiring manager recommendation to showcase **Business Intelligence, visualization, and storytelling** on top of your data platform.

---

## 1. Data Sources Generated for Power BI

The pipeline produces two Power BI-ready datasets in `data/gold/`:

| Dataset Path | Format | Description |
| :--- | :---: | :--- |
| **`data/gold/powerbi_customer_risk_profiles.csv`** (or `.parquet`) | CSV / Parquet | 800 transaction records with calibrated risk scores, behavioral features, fraud labels, and automated policy decisions (`APPROVE`, `MANUAL_REVIEW`, `DECLINE`). |
| **`data/gold/powerbi_decile_summary.csv`** | CSV | 10-decile rank-ordered risk table with Lift, Cumulative Fraud %, and monetary exposure by decile. |

> To refresh or regenerate these datasets at any time, run:
> ```bash
> py src/dashboard/export_for_powerbi.py
> ```

## 2. Step-by-Step Power BI Setup

### Step 1: Import Data into Power BI Desktop
1. Open **Power BI Desktop**.
2. Click **Get Data** ➔ **Text/CSV** (or select **Parquet** if connecting directly to parquet).
3. Browse to your repository:
   - `c:\workspace\public\AegisLake\data\gold\powerbi_customer_risk_profiles.csv`
   - Click **Load**.
4. Repeat for the summary table:
   - `c:\workspace\public\AegisLake\data\gold\powerbi_decile_summary.csv`
   - Click **Load**.

## 3. Recommended DAX Measures

In Power BI, click **New Measure** on the `powerbi_customer_risk_profiles` table and paste the following business metrics:

```dax
// 1. Total Transaction Volume ($)
Total Transaction Volume = SUM(powerbi_customer_risk_profiles[amount])

// 2. Total Fraud Exposure Intercepted ($)
Fraud Loss Intercepted = 
CALCULATE(
    SUM(powerbi_customer_risk_profiles[amount]),
    powerbi_customer_risk_profiles[decision] = "DECLINE",
    powerbi_customer_risk_profiles[is_fraud] = 1
)

// 3. Automated Approval Rate (%)
Auto Approval Rate Pct = 
DIVIDE(
    CALCULATE(COUNTROWS(powerbi_customer_risk_profiles), powerbi_customer_risk_profiles[decision] = "APPROVE"),
    COUNTROWS(powerbi_customer_risk_profiles),
    0
) * 100

// 4. Manual Review Triage Rate (%)
Manual Review Rate Pct = 
DIVIDE(
    CALCULATE(COUNTROWS(powerbi_customer_risk_profiles), powerbi_customer_risk_profiles[decision] = "MANUAL_REVIEW"),
    COUNTROWS(powerbi_customer_risk_profiles),
    0
) * 100

// 5. Model Precision in Decline Tier (%)
Decline Precision Pct = 
DIVIDE(
    CALCULATE(COUNTROWS(powerbi_customer_risk_profiles), powerbi_customer_risk_profiles[decision] = "DECLINE", powerbi_customer_risk_profiles[is_fraud] = 1),
    CALCULATE(COUNTROWS(powerbi_customer_risk_profiles), powerbi_customer_risk_profiles[decision] = "DECLINE"),
    0
) * 100
```

## 4. Executive Dashboard Layout (Visual Blueprint)

Build a 1-page executive dashboard with the following structure:

### 📌 Top Row: Executive KPI Cards
- **Card 1**: `Total Transaction Volume` (Formatted as Currency: `$175K+`)
- **Card 2**: `Fraud Loss Intercepted` (Formatted as Currency: `$95K+`)
- **Card 3**: `Auto-Approval Rate` (Formatted as Percentage: `~80%`)
- **Card 4**: `Manual Review Queue` (Count & Percentage: `~15%`)

### 📈 Middle Section: Risk Separation & Policy Distribution
- **Left: 10-Decile Cumulative Fraud Capture & Lift**
  - **Visual**: *Line and Clustered Column Chart*
  - **Data Source**: `powerbi_decile_summary`
  - **Shared Axis**: `decile` (D1 to D10)
  - **Column Values**: `fraud_count` or `fraud_amount`
  - **Line Values**: `cum_fraud_pct`
  - *Storytelling Insight*: Decile 1 and 2 capture over **87.5%** of all fraud, demonstrating clean risk concentration.
- **Right: Automated Policy Decision Split**
  - **Visual**: *Donut Chart*
  - **Legend**: `decision` (`APPROVE`, `MANUAL_REVIEW`, `DECLINE`)
  - **Values**: Count of `transaction_id`
  - **Colors**: Green (`APPROVE`), Amber/Yellow (`MANUAL_REVIEW`), Red (`DECLINE`).

### 🔍 Bottom Section: Behavioral Anomalies & Merchant Breakdown
- **Left: Merchant Category Risk Heatmap**
  - **Visual**: *Clustered Bar Chart*
  - **Y-Axis**: `merchant_category` (e.g. `electronics`, `crypto_exchange`, `grocery`)
  - **X-Axis**: `is_fraud` (Sum) and `amount` (Average)
- **Right: Customer Risk Profile Table**
  - **Visual**: *Table / Matrix*
  - **Columns**: `user_id`, `risk_score`, `txn_cnt_1h`, `distinct_devices_7d`, `amt_to_avg_ratio`, `decision`
